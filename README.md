# GOOT Luxury — Global bilingual scroll experience

A standalone premium frontend concept for GOOT Resorts.

## Included
- Arabic RTL + English LTR language switch with persistent preference.
- Scroll-directed cinematic animation.
- Responsive mobile navigation.
- Interactive 3D-style villa scene.
- Resort stays selector.
- Gallery, dining, service and reservation sections.
- SEO metadata, canonical/hreflang tags, Open Graph metadata and Schema.org Resort JSON-LD.
- Manifest, robots.txt and sitemap starter.
- Accessibility basics: skip link, labels, live status, reduced motion and keyboard controls.
- Security/production checklist.

## Run
Any static server can serve the folder. Example:
`python -m http.server 8080`
Then open `http://localhost:8080`.

The reservation form is intentionally a frontend flow only. It must be connected to an authorized live booking API before production.
